# Dark Office

Dark Office business automation website.

## GitHub Pages setup

1. Create a repository named `dark-office`.
2. Upload the contents of this folder to the **repository root**.
3. Commit to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site.

### Important
Do not upload the `dark-office-github` folder itself as a nested folder. The repository root should directly contain:

- `index.html`
- `styles.css`
- `script.js`
- `404.html`
- `.nojekyll`
- `assets/`

## Contact form

The form in `index.html` is prepared for FormSubmit. The contact form is configured to send inquiries to:

`Ops.darkoffice@gmail.com`

No server, Node.js, PHP, or build process is required.
